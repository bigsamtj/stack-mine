    How we classify AI products

    Ordered by how much the vendor documents the product acting on its own. We use a stronger label only when documentation supports it.

    Less autonomousMore autonomous
    1. 1Software with AI features

      Conventional software that includes AI features rather than being built around an agent.

    2. 2AI assistant

      Answers questions and suggests content or code; the user performs the actions.

    3. 3Agentic tool

      A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes.

    4. 4Autonomous agent

      Completes multi-step tasks with tools and limited supervision, as documented by the vendor.

    Editorial standards

    Evidence first, with unknowns labelled.

    The rules every profile is held to before it is published.

    Sourced and dated

    Pricing, features and integrations come from vendor pages and documentation where possible, with the source and the date it was accessed shown on each profile.

    Honest about gaps

    When something is not documented in the sources we reviewed, the profile says so. We do not infer security certifications, autonomy levels or model capabilities.

    No paid placement

    This directory contains no paid placements, affiliate links, ratings or reviews. External links to vendor sites are labelled.

    Check before you buy

    Prices and plans change. Each profile links to the official pages so you can confirm current terms with the vendor.
