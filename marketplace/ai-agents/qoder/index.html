Quick answer

What is Qoder?

Qoder is an agentic coding platform from Alibaba, launched in August 2025, available as a desktop IDE, a JetBrains plugin, a CLI and a mobile app. It offers an Agent mode for checkpointed pair programming and a Quest mode that implements multi-file features autonomously, on credit-based plans.

Overview

Qoder overview: who it is for and what it does.

Qoder launched on 21 August 2025 as Alibaba's entry into agentic IDEs and reached version 1.0 in May 2026. It is available as a standalone IDE for macOS, Windows and Linux, a JetBrains plugin, a CLI and a mobile app for monitoring agents.

Two modes define it. Agent mode is collaborative pair programming with checkpoints; Quest mode takes a specification and works autonomously through a multi-file feature. Repo Wiki generates documentation of a repository, and an Experts mode runs parallel specialist agents.

Pricing is credit-based. Qoder's pricing documentation lists Free, Pro at $20, Pro+ at $60 and Ultra at $200 a month with 2,000 to 20,000 credits, though some trackers list Pro at $30. A Teams plan at $40 a seat is reported. The international edition is run from Singapore, while Qoder CN (formerly Tongyi Lingma) serves mainland China.

Main problem it solves

Gives developers an agentic IDE that can implement whole features from a specification, with documentation of the codebase generated automatically.

FAQ

Qoder questions and answers

What is Qoder used for?

Qoder is used to write code with an AI agent, implement multi-file features autonomously in Quest mode and generate repository documentation.

Is Qoder free?

Yes. The Free plan includes unlimited completions with basic models and limited credits, and supports bring-your-own-key.

How much does Qoder cost?

Free plan; Pro $20, Pro+ $60 and Ultra $200 per month; Teams about $40 per seat. Agent requests use about 50 credits each at the median, per one 2026 guide.

Which models does Qoder support?

Multi-model routing across Qwen, Claude and GPT families, per third-party reviews.

Who makes Qoder?

Qoder is made by Alibaba. It launched in August 2025 and reached version 1.0 in May 2026.

Is Qoder the same as Tongyi Lingma?

Not exactly. Qoder CN, the edition for mainland China, is the former Tongyi Lingma; the international Qoder is a separate edition run from Singapore.

What are the limitations of Qoder?

Credit consumption per operation is not always clear in advance. Published Pro pricing differs between the vendor documentation and trackers. Some enterprises have data-handling concerns about an Alibaba product.

Which platforms does Qoder run on?

Qoder is documented as available on: Desktop IDE (macOS, Windows, Linux), JetBrains plugin, CLI, Mobile app.

Is Qoder an AI agent or an AI assistant?

We classify Qoder as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

What are the main alternatives to Qoder?

The main alternatives to Qoder covered on Stack18 are Cursor, Trae, Kiro and Windsurf. See the Qoder alternatives guide for a side-by-side table.
