Quick answer

What is Kimi Code?

Kimi Code is Moonshot AI's open-source command-line coding agent. It reads and edits code, runs shell commands, searches files and fetches web pages, powered by Kimi models such as K2.6, K2.7 Code and K3, and supports MCP, ACP for editors and a VS Code extension.

  • Best forDevelopers who want a low-cost terminal agent
  • PricingFree CLI; Kimi memberships from $180 a year (Plus) to $1,908 a year (Ultra), or API usage. Free plan available.
  • Main limitationPricing and membership tiers changed several times in 2026.
  • AlternativesQwen Code · Claude Code · OpenCode · compare all

Overview

Kimi Code overview: who it is for and what it does.

Moonshot released the Python-based kimi-cli in October 2025 and a TypeScript rewrite, kimi-code, in May 2026. The tool itself is free and open source; access to models comes through a Kimi membership with a dedicated Kimi Code credit pool, or pay-as-you-go Moonshot API credits.

Pricing has moved several times. Memberships were renamed Plus, Pro, Max and Ultra in September 2026 (Plus $180 a year, Ultra $1,908 a year), after a July pause in new subscriptions for capacity reasons following the K3 launch. API rates for K2.7 Code were reported at $0.95 input and $4.00 output per million tokens.

Main problem it solves

Gives developers a low-cost terminal agent driving open-weight Kimi models.

Typical customer segment

Individual developers; Moonshot API customers.

Target users

  • Users of Kimi models

Primary use cases

  • Using Kimi Code from Zed or JetBrains via ACP
  • MCP tool use
  • VS Code extension use

What makes it distinct

  • Open-source CLI with open-weight Kimi models.
  • Separate Kimi Code credit pool in membership.
  • ACP support for editor integration.

FAQ

Kimi Code questions and answers

What is Kimi Code used for?

Kimi Code is Moonshot AI's open-source command-line coding agent. It reads and edits code, runs shell commands, searches files and fetches web pages, powered by Kimi models such as K2.6, K2.7 Code and K3, and supports MCP, ACP for editors and a VS Code extension.

Is Kimi Code free?

The CLI is free and open source; service access needs a paid membership or API credits.

How much does Kimi Code cost?

Free CLI; Kimi memberships from $180 a year (Plus) to $1,908 a year (Ultra), or API usage.

Which models does Kimi Code support?

Kimi K2.6, K2.7 Code and K3 open-weight models.

What are the limitations of Kimi Code?

Pricing and membership tiers changed several times in 2026. New subscriptions were paused in July 2026 for capacity. The TypeScript rewrite is young.

Which platforms does Kimi Code run on?

Kimi Code is documented as available on: Terminal (macOS, Linux, Windows), VS Code extension, ACP editors.

Is Kimi Code an AI agent or an AI assistant?

We classify Kimi Code as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

What are the main alternatives to Kimi Code?

The main alternatives to Kimi Code covered on Stack18 are Qwen Code, Claude Code, OpenCode and Gemini CLI. See the Kimi Code alternatives guide for a side-by-side table.
