Quick answer

What is Trae?

Trae is an AI-native IDE from ByteDance, built on a VS Code base, that combines code completion and chat with SOLO, an agent mode for larger autonomous tasks on desktop and web. Since February 2026 it uses token-based plans from Free and Lite at $3 to Ultra at $100 a month.

Overview

Trae overview: who it is for and what it does.

Trae is a desktop IDE from ByteDance built on a VS Code base, so extensions and settings carry over. It adds autocomplete, chat and agent modes, including SOLO, which can take on larger autonomous tasks and run cloud tasks in parallel.

On 24 February 2026 Trae moved from request-based to token-based billing and introduced five plans. Free includes 5,000 autocompletions a month and limited SOLO use; Lite costs $3, Pro $10, Pro+ $30 and Ultra $100 a month, each with a dollar-denominated usage allowance.

Reviewers note two caveats: heavier agent use burns through token allowances faster than the old request model, and some organisations have data-handling questions about a ByteDance product, so policy review is advisable before using it on sensitive code.

Main problem it solves

Offers a low-cost AI IDE with an autonomous agent mode for developers who want frontier models without a $20 a month subscription.

What makes it distinct

FAQ

Trae questions and answers

What is Trae used for?

Trae is used as a low-cost AI IDE for writing code with autocomplete, chat and the SOLO agent mode for larger autonomous tasks.

Is Trae free?

Yes. Free includes 5,000 autocompletions a month, limited SOLO use and two concurrent cloud tasks.

How much does Trae cost?

Free plan; Lite $3, Pro $10, Pro+ $30 and Ultra $100 per month. Usage is metered by tokens, so heavy agent sessions use allowances faster.

Which models does Trae support?

Premium models including Claude and GPT families are reported on Free and paid plans.

Is Trae free?

Yes, Trae has a Free plan with 5,000 autocompletions a month and limited SOLO use. Paid plans start at $3 a month.

Who makes Trae?

Trae is developed by ByteDance.

What are the limitations of Trae?

Token-based billing since February 2026 makes heavy agent sessions use allowances quickly. Data-handling questions about a ByteDance product may block use on sensitive code. Enterprise pricing is not public.

Which platforms does Trae run on?

Trae is documented as available on: Desktop IDE (macOS, Windows), Web (SOLO).

Is Trae an AI agent or an AI assistant?

We classify Trae as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

What are the main alternatives to Trae?

The main alternatives to Trae covered on Stack18 are Cursor, Windsurf, Qoder and Google Antigravity. See the Trae alternatives guide for a side-by-side table.
