Quick answer

What is Jules?

Jules is an asynchronous, agentic coding assistant from Google Labs, powered by Gemini models. It integrates with GitHub, clones a repository into a Google Cloud virtual machine, plans and makes changes, and proposes them for the developer to review.

  • Best forDelegating routine engineering tasks
  • PricingFree (15 tasks a day); Jules in Google AI Pro ($19.99 per month) and Ultra (price varies by report). Free plan available.
  • Main limitationTask caps and concurrency limits apply on every plan.
  • AlternativesDevin, GitHub Copilot, OpenAI Codex, OpenHands · compare all

Reviewed by the Stack18 editorial team · 3 sources

Overview

Jules overview: who it is for and what it does.

Jules is built for delegation. Google describes it as an asynchronous coding agent that integrates directly with existing repositories: a developer hands it a task such as fixing a bug, writing tests or updating a dependency, and Jules works in the background while the developer does something else. TechCrunch reports that Jules clones codebases into Google Cloud virtual machines and works with GitHub.

Jules left beta in August 2025 with structured plans. Google's announcement describes an introductory free plan, and Jules in Google AI Pro and Google AI Ultra with 5x and 20x higher limits. Limits are expressed as daily tasks and concurrent tasks: Google's pages, as quoted by a tracker, list 100 daily and 15 concurrent tasks on Pro, and 300 daily and 60 concurrent tasks on Ultra, while the free plan has 15 daily and 3 concurrent tasks.

There is no standalone Jules subscription; paid access comes with Google AI plans. Reports on the price of Google AI Ultra differ ($124.99, $249.99 and $99.99 appear in different articles), so confirm it on Google's page. One review says paid Jules plans required a personal Google account rather than Workspace at the time it was written.

Main problem it solves

Lets developers hand routine engineering tasks to a background agent that works in an isolated cloud environment and returns a pull request, instead of working interactively.

Typical customer segment

Individuals (free and Google AI plans), with enterprise access through Google Cloud sales for Google AI Ultra in Workspace, per reports.

Target users

  • Developers who want to delegate bug fixes, tests and dependency updates
  • Teams that already use GitHub and Google AI plans
  • Developers who want to run several tasks in parallel

Primary use cases

  • Fixing bugs and writing tests in the background
  • Upgrading dependencies or runtime versions
  • Opening pull requests for review
  • Running several agent tasks in parallel on Pro or Ultra
  • Scheduled and suggested tasks on paid plans

What makes it distinct

  • Works asynchronously in a cloud VM and returns pull requests.
  • Included in Google AI plans rather than sold separately.
  • Task-based limits (daily and concurrent) instead of per-token billing.

FAQ

Jules questions and answers

What is Google Jules?

Jules is Google's asynchronous coding agent. It clones your repository into a cloud VM, works on a task in the background and proposes changes for review.

Is Jules free?

Yes. Google offers an introductory free plan with 15 tasks per day and 3 concurrent tasks, as quoted from Google's pages by a tracker.

How much does Jules cost?

Jules has no standalone price. It is bundled with Google AI Pro ($19.99 per month) and Google AI Ultra, whose price differs between reports, with 5x and 20x higher limits.

What model does Jules use?

Jules uses Google's Gemini models. Google's launch post cites Gemini 2.5 Pro, and third-party reviews list newer Gemini versions on current tiers.

Does Jules work with GitHub?

Yes. Google says Jules integrates directly with existing repositories, and TechCrunch says it integrates with GitHub.

Is Jules an autonomous agent?

We classify it as an autonomous agent because Google describes it as asynchronous and agentic, working in the background. Developers still review the proposed changes.

How does Jules compare with Devin?

Both delegate tasks to cloud agents. Jules is bundled with Google AI plans and limited by task counts, while Devin has its own plans and quotas. See the Devin vs Jules comparison.

What integrations does Jules support?

Documented integrations and ecosystem items include GitHub, Google Cloud VMs, Gemini models, Google AI Pro and Ultra. API details: Not reviewed for this profile.

What are the limitations of Jules?

Task caps and concurrency limits apply on every plan. Reports on the price of Google AI Ultra conflict. Uses Gemini models only.

Which platforms does Jules run on?

Jules is documented as available on: Web.

Is Jules an AI agent or an AI assistant?

We classify Jules as: Autonomous agent. Completes multi-step tasks with tools and limited supervision, as documented by the vendor. The classification is based on vendor documentation and is not an endorsement.

When was the Jules profile last verified?

3 sources are listed under Sources. Prices and plans can change, so confirm with the vendor.

What are the main alternatives to Jules?

The main alternatives to Jules covered on Stack18 are Devin, GitHub Copilot, OpenAI Codex and OpenHands. Devin may suit teams that want to delegate engineering tasks to a cloud agent. GitHub Copilot may suit developers and teams standardised on GitHub. OpenAI Codex may suit ChatGPT subscribers who write code. See the Jules alternatives guide for a side-by-side table.
