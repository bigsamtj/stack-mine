Quick answer

What is Rork?

Rork is an AI app builder focused on mobile. It turns natural-language prompts into real React Native (Expo) apps for iOS and Android, with preview and publishing to the App Store and Google Play, and meters usage by AI messages.

  • Best forFounders building mobile apps
  • PricingMessage-based subscriptions (figures not recorded).

Overview

Rork overview: who it is for and what it does.

Rork generates cross-platform mobile apps in React Native using Expo, so the output is native code that teams can own and maintain. It targets founders and makers who want an app in the stores without writing it by hand.

Pricing is metered by AI messages rather than seats, so the number of iterations an app needs drives the cost. Sources disagree on whether a free plan exists; check rork.com/pricing.

Main problem it solves

Gets mobile app ideas into the App Store and Google Play without hand-coding.

Typical customer segment

Founders, makers and small teams.

Target users

  • Non-developers building tools
  • Developers prototyping quickly

Primary use cases

  • React Native and Expo code
  • Store publishing
  • Rapid mobile prototypes

What makes it distinct

  • Mobile-first, with native React Native output.
  • Built on Expo.
  • Message-metered pricing.
