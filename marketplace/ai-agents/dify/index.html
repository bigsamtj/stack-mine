Quick answer

What is Dify?

Dify is an open-source platform from LangGenius for building and running LLM applications: agents, agentic workflows, chatbots and RAG pipelines, designed on a visual canvas and published as web apps, APIs, embeds or MCP-compatible tools. It is available as free self-hosted software and as Dify Cloud.

  • Best forDevelopers building RAG chatbots and agents
  • PricingFree self-hosted; Cloud Professional $59 and Team $159 a month; Enterprise custom. Free plan available.
  • Main limitationLicence is not OSI-approved open source.
  • AlternativesFlowise · Langflow · Stack AI · compare all

Reviewed by the Stack18 editorial team · 8 sources

Overview

Dify overview: who it is for and what it does.

Dify combines a Workflow Studio (model calls, knowledge retrieval, tools, code, branching, triggers and human review on a collaborative canvas), a Knowledge Pipeline for RAG, prompt management and a plugin marketplace, with support for 100+ model providers including OpenAI, Anthropic, Google and local models. Apps can be published as web apps, APIs or MCP tools. Its GitHub repository has more than 130,000 stars and LangGenius reports 280+ enterprise customers.

The Community Edition is free to self-host under the Dify Open Source License, which adds conditions to Apache 2.0. Dify Cloud is priced per workspace: Sandbox is free with 200 message credits, Professional is $59 a month and Team $159 a month ($590 and $1,590 annually since a July 2026 redesign), and Enterprise is custom with SSO and on-premises options. Dify reports SOC 2, ISO 27001 and GDPR compliance.

Dify questions and answers

What is Dify used for?

Dify is an open-source platform from LangGenius for building and running LLM applications: agents, agentic workflows, chatbots and RAG pipelines, designed on a visual canvas and published as web apps, APIs, embeds or MCP-compatible tools. It is available as free self-hosted software and as Dify Cloud.

Is Dify free?

Yes. Self-hosting is free, and Dify Cloud Sandbox includes 200 message credits.

How much does Dify cost?

Free self-hosted; Cloud Professional $59 and Team $159 a month; Enterprise custom.

Which models does Dify support?

100+ providers including OpenAI, Anthropic, Google and local models.

What are the limitations of Dify?

Licence is not OSI-approved open source. SSO, RBAC and audit logs gated to paid plans. Cloud Sandbox has a 200-credit cap.

Which platforms does Dify run on?

Dify is documented as available on: Self-hosted (Docker), Dify Cloud, API, Web apps.

Is Dify an AI agent or an AI assistant?

We classify Dify as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

What are the main alternatives to Dify?

The main alternatives to Dify covered on Stack18 are Flowise, Langflow, Stack AI and Microsoft Copilot Studio. See the Dify alternatives guide for a side-by-side table.
