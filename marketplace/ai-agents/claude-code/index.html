Quick answer

What is Claude Code?

Claude Code is Anthropic's agentic coding tool. It runs in a terminal, in VS Code and JetBrains extensions, in a desktop app and on the web, and uses Claude models with tools, permissions and subagents.

Overview

Claude Code overview: who it is for and what it does.

Claude Code is a coding tool from Anthropic that developers direct in natural language. Anthropic's documentation covers use from the terminal CLI, IDE extensions for VS Code and JetBrains, a desktop app and Claude Code on the web, along with GitHub Actions and a Code Review feature.

The documentation emphasises control and extensibility. It describes a permission system used together with sandboxing for defence in depth, checkpoints, MCP servers for connecting external tools, hooks, skills, plugins and custom subagents. A CLAUDE.md file provides project instructions that are read at the start of every session.

Access is through paid Claude plans (Pro, Max, Team and Enterprise) or usage-based billing through an API key or a chosen cloud provider, according to third-party summaries of Anthropic's documentation. Disclosure: Anthropic also makes the Claude assistant, and this profile applies the same sourcing rules as every other listing.

Main problem it solves

Lets developers delegate multi-step coding tasks, such as exploring a codebase, refactoring and running tests, to an AI tool that works in their own environment under configurable permissions.

Typical customer segment

Individual developers through enterprises, via Pro, Max, Team and Enterprise plans or usage-based API billing.

Target users

  • Developers who work in the terminal or want one tool across terminal, IDE and web
  • Teams that want to standardise project instructions, permissions and extensions
  • Organisations that want centrally managed settings

Primary use cases

  • Exploring and explaining a codebase
  • Refactoring across files
  • Running tasks in parallel with subagents or Git worktrees
  • Automating code review and CI tasks
  • Connecting external tools through MCP

What makes it distinct

  • Runs on several surfaces: terminal, VS Code, JetBrains, desktop and web.
  • A documented permission and sandboxing model, with checkpoints.
  • Extensibility through MCP, hooks, skills, plugins and subagents.
Key features

Claude Code features explained.

Where it runs

Terminal CLI
The core interface, installed as a command-line tool and started inside a project directory.
IDE extensions
Extensions for VS Code and JetBrains IDEs.
Desktop app and web
A desktop app and Claude Code on the web at claude.ai/code, with documented ways to move tasks between web and terminal.

Control and safety

Permissions
Rules that block or allow specific tools and commands, for example denying shell access with a deny rule.
Sandboxing
Anthropic's documentation describes permissions and sandboxing used together as defence in depth.
Checkpoints
Documented as part of how to stay safe when working with Claude Code.

Context and extensibility

CLAUDE.md project instructions
A file that Claude Code reads at the start of every session.
Subagents
Custom subagents with their own context, tools and permissions that return a summary to the main conversation.
MCP servers, hooks, skills and plugins
Connect external tools and customise behaviour; plugins bundle skills, MCP connectors and subagents.

Automation

GitHub Actions and Code Review
The documentation covers a Claude Code GitHub Actions integration and a Code Review feature.
Parallel sessions
Documentation covers running parallel Claude Code sessions with Git worktrees.

Strengths, limitations and best fit

Claude Code pros and cons.

Strengths, limitations and best fit. Each point cites a source; editorial summaries are not customer reviews.

Strengths

  • Runs in the terminal, VS Code, JetBrains, a desktop app and the web, so one tool can follow a developer across environments. [1]
  • Anthropic documents a permission system used with sandboxing, plus checkpoints, which gives teams concrete oversight controls to evaluate. [1]
  • Extensible through MCP servers, hooks, skills, plugins and subagents with their own context windows. [1]
  • A CLAUDE.md file lets teams give the tool persistent project instructions that load every session. [1]

Limitations

  • The documentation reviewed describes Claude models only, so teams wanting a choice of model vendors may prefer a multi-vendor product. [2]
  • Subscription usage is limited and measured in rolling five-hour and weekly windows, which heavy users should plan for. [3]
  • No free tier was identified in the sources reviewed, so evaluation requires a paid plan or API usage. [2]
  • Pricing was not reviewed on Anthropic's own pricing pages for this profile, so cost comparisons need a check of the live page. [3]

Best for

  • Terminal-first developers
  • Teams that want documented permission and sandbox controls
  • Workflows that use subagents, MCP integrations or CI automation

May be less suited to

  • Teams that want to switch freely between model vendors in one product
  • Developers who want an editor-centred experience as the primary interface

FAQ

Claude Code questions and answers

What is Claude Code used for?

Claude Code is used to explore, edit and refactor codebases and to run commands and tests from the terminal, IDE extensions, a desktop app or the web, under a configurable permission system.

Is Claude Code an autonomous agent?

We classify it as an agentic tool. It can plan and act, but the documentation describes permissions, sandboxing and checkpoints that keep the developer in control, and it does not describe fully autonomous operation.

Does Claude Code have a free plan?

No free tier was identified in the sources reviewed. It is described as part of paid Claude plans or available with usage-based API billing. Confirm on Anthropic's pricing page.

Which models does Claude Code use?

It uses Claude models from Anthropic. Usage can be billed through an API key or a chosen cloud provider.

How does Claude Code compare with Cursor?

Claude Code is terminal-first and also runs in IDEs, a desktop app and the web, using Claude models. Cursor is an editor with models from several vendors. See the Cursor vs Claude Code comparison.

What integrations does Claude Code support?

Documented integrations and ecosystem items include MCP servers, VS Code and JetBrains, GitHub Actions, Git worktrees, Skills, hooks and plugins. API details: Anthropic documents an Agent SDK for building agents on the same runtime. API details for Claude Code itself were not reviewed.

What are the limitations of Claude Code?

The documentation reviewed describes Claude models only, so teams wanting a choice of model vendors may prefer a multi-vendor product. Subscription usage is limited and measured in rolling five-hour and weekly windows, which heavy users should plan for. No free tier was identified in the sources reviewed, so evaluation requires a paid plan or API usage.

Which platforms does Claude Code run on?

Claude Code is documented as available on: Terminal (CLI), VS Code, JetBrains, Desktop app, Web.

Is Claude Code an AI agent or an AI assistant?

We classify Claude Code as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.
