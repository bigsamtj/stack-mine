Quick answer

What is Aider?

Aider is an open-source command-line tool for pair programming with large language models. It edits files in a local git repository, builds a map of the repo for context, and works with almost any LLM, including local models.

  • Best forDevelopers who live in the terminal and use git heavily
  • PricingFree open-source tool; you pay only for the LLM you connect. Free plan available.
  • Main limitationTerminal-based, so it has a steeper learning curve for developers who prefer a graphical editor.
  • AlternativesCline, Claude Code, Gemini CLI, OpenAI Codex · compare all

Reviewed by the Stack18 editorial team · 5 sources

Overview

Aider overview: who it is for and what it does.

Aider runs in the terminal inside a git repository. According to its documentation, you add files to the chat so Aider can edit them, and Aider includes relevant context from the rest of the repository. It can connect to almost any LLM, including local models, and you can switch models during a chat with the /model command.

Aider's documentation lists in-chat commands, chat modes (code, architect, ask and help), voice-to-code, adding images and web pages, prompt caching, linting and testing, a watch mode for use from an IDE, a browser mode and a way to copy and paste with web chat interfaces. Third-party descriptions say Aider commits each change to git, which makes edits easy to review and undo, and uses a tree-sitter based repo map to work on larger codebases.

Aider is installed with Python, with installation methods documented for Python 3.8 to 3.13. Third-party sources describe it as Apache-2.0 licensed, and its repository history shows the Apache 2.0 licence was added in 2023. The tool itself is free; you pay your model provider for usage. We did not verify the project's current release cadence, so check its repository before relying on it.

Main problem it solves

Lets developers use any LLM to edit a git repository from the terminal while keeping every change as a reviewable commit.

Primary use cases

  • Fixing bugs from pasted errors or issue URLs
  • Refactoring and updating documentation
  • Fixing lint and test failures automatically

What makes it distinct

  • Works with almost any LLM, including local models.
  • Chat modes such as architect and ask separate planning from editing.

FAQ

Aider questions and answers

What is Aider?

Aider is an open-source command-line tool for AI pair programming. It edits code in your local git repository using a large language model of your choice.

Is Aider free?

Yes. Aider itself is free open-source software. You pay your LLM provider for usage, or you can use local models.

Which models work with Aider?

Aider's documentation says it can connect to almost any LLM, including local models, and it names specific models that work best. Check the documentation for current recommendations.

Does Aider commit changes to git?

Third-party descriptions say Aider commits each change with a descriptive message, which makes edits easy to review and undo.

Is Aider an autonomous agent?

We classify Aider as an agentic tool. It makes multi-file edits and can run lint and tests, but the developer directs the work and reviews the commits.

How do I install Aider?

Aider's documentation describes aider-install, one-line installers for macOS, Linux and Windows, and installs with uv, pipx or pip.

How does Aider compare with Claude Code?

Both run in the terminal. Aider is open source and model-agnostic, while Claude Code is Anthropic's tool using Claude models. See the Claude Code vs Aider comparison.

What integrations does Aider support?

Documented integrations and ecosystem items include Any LLM provider with an API key, Local models, Git repositories, IDE watch mode, Docker and GitHub Codespaces. API details: Aider connects to model providers using their APIs and OpenAI-compatible endpoints.

What are the limitations of Aider?

Terminal-based, so it has a steeper learning curve for developers who prefer a graphical editor. The developer must select the files to add to the chat for best results. The documentation's model recommendations can lag newer model releases.

Which platforms does Aider run on?

Aider is documented as available on: Command line (macOS, Linux, Windows), Docker, GitHub Codespaces.

Is Aider an AI agent or an AI assistant?

We classify Aider as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

When was the Aider profile last verified?

5 sources are listed under Sources. Prices and plans can change, so confirm with the vendor.

What are the main alternatives to Aider?

The main alternatives to Aider covered on Stack18 are Cline, Claude Code, Gemini CLI and OpenAI Codex. Cline may suit developers who prefer open-source tools and their own API keys. Claude Code may suit Terminal-first developers. Gemini CLI may suit developers who want to start free in the terminal. See the Aider alternatives guide for a side-by-side table.
