Quick answer

What is Tabby?

Tabby is an open-source (Apache 2.0), self-hosted AI coding assistant from TabbyML, written in Rust. It provides code completion, an answer engine, inline chat, data connectors and an MCP agent mode, running entirely on your own infrastructure with open-weight models.

  • Best forTeams that must self-host
  • PricingCommunity free (up to 5 users); Team about $19 per user per month; Enterprise custom. Free plan available.
  • Main limitationRequires GPU hardware to self-host.
  • AlternativesTabnine · Refact.ai · Continue · compare all

Reviewed by the Stack18 editorial team · 4 sources

Overview

Tabby overview: who it is for and what it does.

Tabby is a self-hosted alternative to cloud copilots: install the server on your own GPUs, connect VS Code or JetBrains, and keep code inside your network. It has about 33,000 GitHub stars and partners with Mistral, DeepSeek and Qwen for models.

Community is free for up to 5 users, Team costs about $19 per user a month and Enterprise adds SSO and audit logs. Self-hosting requires GPU hardware, which is the main hidden cost.

Main problem it solves

Gives security-conscious teams AI completion and chat without code leaving their network.

Typical customer segment

Teams of any size that self-host.

Target users

  • Security-conscious engineering teams
  • Organisations with data-residency rules
  • Developers running open-weight models

Primary use cases

  • Self-hosted code completion
  • Chat and answer engine over internal code
  • MCP agent mode
  • Air-gapped environments

What makes it distinct

  • Fully self-hosted.
  • Open source under Apache 2.0.
  • Free for up to 5 users.
