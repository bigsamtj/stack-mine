Quick answer

What is Cursor?

Cursor is an AI-native code editor from Anysphere that combines an in-editor Agent, Tab autocomplete and cloud agents, with access to models from OpenAI, Anthropic and Google alongside Cursor's own models.

  • Best forDevelopers who prefer an editor-centred workflow
  • PricingFree Hobby plan; Pro $20 per month. Free plan available.
  • Main limitationUsage is metered at model API prices against an included amount, so heavy agent users may incur on-demand charges.

Overview

Cursor overview: who it is for and what it does.

Cursor is a code editor built around AI assistance. Its pricing page lists an Agent that developers can use for coding tasks, Tab completions powered by Cursor's own models, cloud agents, and Bugbot for agentic code review. Paid plans add extended Agent limits, access to frontier models, and support for MCP servers, skills and hooks.

Cursor describes itself as powered by a combination of custom models and models from other vendors. Its pricing documentation lists usage in terms of model API prices: individual plans include an amount of agent usage, and on-demand usage can continue after the included amount is consumed, billed in arrears.

For organisations, Teams adds shared chats, commands and rules, centralised billing and administration, org-wide Privacy Mode controls and SAML or OIDC single sign-on. Enterprise is custom-priced for organisations that need invoicing, pooled usage or advanced security.

Main problem it solves

Helps developers write, edit and review code faster by putting an AI agent, autocomplete and code review inside the editor where they already work.

Typical customer segment

Individuals through enterprises, with Hobby, Pro, Pro+, Ultra, Teams and Enterprise plans.

Target users

  • Individual developers who want an AI-native editor
  • Engineering teams that want shared rules and org-wide privacy controls
  • Organisations needing invoicing, pooled usage and advanced security on Enterprise

Primary use cases

  • Multi-file feature work with an in-editor agent
  • Autocomplete with Tab
  • Agentic code review with Bugbot
  • Running agents in the cloud
  • Connecting tools through MCP, skills and hooks

What makes it distinct

  • Models from several vendors in one product, plus Cursor's own models for features such as Tab.
  • An editor-centred workflow with the agent, completions and review in one place.
  • Org-wide Privacy Mode enforcement and SSO on team plans.
Key features

Cursor features explained.

Coding assistance

Agent
An in-editor agent for coding tasks. The free Hobby plan includes limited Agent requests; paid plans extend the limits.
Tab completion
Cursor's native autocomplete, powered entirely by Cursor's custom models according to its pricing FAQ.
Max Mode
Certain models can use Max Mode for longer reasoning and larger context windows, up to 1M tokens according to Cursor's documentation.

Agents and review

Cloud agents
Agents that run remotely. Cursor's documentation says cloud agents are charged at model API pricing.
Bugbot
Agentic code review. Cursor lists Bugbot as available on usage-based billing for individuals and included for agentic code reviews on Teams.

Extensibility

MCP servers, skills and hooks
Listed on Pro and above for connecting external tools and customising agent behaviour.
Shared rules, commands and chats
Teams adds shared chats, commands and rules, and a team marketplace for internal rules, skills and plugins on some plan versions.

Administration

Org-wide Privacy Mode controls
Teams admins can enforce Privacy Mode across the organisation.
SSO and admin dashboard
Cursor's documentation lists SAML or OIDC SSO, an admin dashboard with usage stats and centralised billing for team plans.

Strengths, limitations and best fit

Cursor pros and cons.

Strengths, limitations and best fit. Each point cites a source; editorial summaries are not customer reviews.

Strengths

  • Offers models from several vendors in one product, so teams are not tied to a single model family. [2]
  • A free Hobby plan lets developers try the editor and agent before paying. [1]
  • Team plans document org-wide Privacy Mode enforcement, SAML or OIDC SSO and an admin dashboard. [3]
  • Certain models can use Max Mode with context windows up to 1M tokens, which is relevant to large codebases. [3]

Limitations

  • Usage is metered at model API prices against an included amount, so heavy agent users may incur on-demand charges. [3]
  • Tab and Apply from Chat run on custom models and cannot be billed to a user's own API key. [2]
  • The plan and price structure changes often, and versions of the pricing page have differed, so budgeting requires checking the live page. [1]
  • Human-approval and permission controls for the agent were not documented in the sources reviewed for this profile. [1]

Best for

  • Developers who prefer an editor-centred workflow
  • Teams that want to choose between several model vendors
  • Organisations that want org-wide Privacy Mode and SSO

May be less suited to

  • Developers who prefer to stay in a terminal-only workflow

FAQ

Cursor questions and answers

What is Cursor used for?

Cursor is used to write, edit and review code with AI help inside an editor. It includes an Agent, Tab autocomplete, cloud agents and Bugbot code review.

Is Cursor an autonomous agent?

We classify it as an agentic tool. It offers an Agent and cloud agents, but vendor documentation reviewed here does not describe it as fully autonomous, and developers direct and review its work.

Does Cursor have a free plan?

Yes. The Hobby plan is free, needs no credit card, and includes limited Agent requests and limited Tab completions.

Which models does Cursor support?

Cursor lists models from OpenAI, Anthropic and Google, and uses its own custom models for features such as Tab. Model access and usage depend on the plan.

How does Cursor compare with Claude Code?

Cursor is an editor-centred product with multi-vendor models, while Claude Code is a terminal-first agentic tool from Anthropic that also runs in IDEs, a desktop app and the web. See the Cursor vs Claude Code comparison.

What integrations does Cursor support?

Documented integrations and ecosystem items include MCP servers, Skills and hooks, OpenAI, Anthropic and Google models, Cloud agents, Bugbot. API details: Cursor says some features, including Tab and Apply from Chat, are powered by custom models and cannot be charged to a user's own API key.

What are the limitations of Cursor?

Usage is metered at model API prices against an included amount, so heavy agent users may incur on-demand charges. Tab and Apply from Chat run on custom models and cannot be billed to a user's own API key. The plan and price structure changes often, and versions of the pricing page have differed, so budgeting requires checking the live page.

Which platforms does Cursor run on?

Cursor is documented as available on: Desktop app (download from cursor.com).

Is Cursor an AI agent or an AI assistant?

We classify Cursor as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.
