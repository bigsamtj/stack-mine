Quick answer

What is Junie?

Junie is JetBrains' AI coding agent. It works inside JetBrains IDEs such as IntelliJ IDEA and PyCharm, and as a beta CLI and GitHub Action, with access through JetBrains AI subscriptions or bring-your-own-key at provider rates.

  • Best forJetBrains IDE users

Overview

Junie overview: who it is for and what it does.

Junie is JetBrains' coding agent, positioned on its site as an agent that works with any model you choose and is powered by IDE capabilities. JetBrains lists a CLI that runs in the terminal, a GitHub Action, persistent project guidelines and Agent Skills packages, and commands shared between the CLI and the IDE via ACP. The site says more than ten models are supported through bring-your-own-key, including local models through Ollama.

Pricing combines JetBrains AI subscriptions and BYOK. JetBrains' blog explains that AI Assistant and Junie share one credit system, with AI Pro suited to light use, AI Ultimate recommended for regular agent use, and an AI Enterprise plan with a larger quota, audit logs, provider selection through BYOK and an on-premises option. Junie's page shows AI Pro at $8.33 per user per month, while third-party sources list $10 per month for Pro and $30 for Ultimate, so the difference is likely billing term and should be confirmed.

Third-party coverage says Junie initially launched in IntelliJ IDEA Ultimate, PyCharm Pro, WebStorm and GoLand, that Codex became an additional agent option in JetBrains IDEs in January 2026, and that Junie CLI is in beta. Junie's own page says BYOK is billed at provider rates with zero markup.

Main problem it solves

Brings an agent that understands the project through the IDE's own engine to JetBrains users, without leaving their IDE.

Typical customer segment

Individuals through enterprises, via JetBrains AI Free, Pro, Ultimate and Enterprise plans or BYOK.

Target users

  • Teams that want an agent in CI with a GitHub Action
  • Organisations that need audit logs and on-premises options

FAQ

Junie questions and answers

What is JetBrains Junie?

Junie is JetBrains' AI coding agent. It works in JetBrains IDEs, as a beta CLI and as a GitHub Action, with any model through bring-your-own-key or a JetBrains AI plan.

Is Junie free?

Junie is free to start with bring-your-own-key, where you pay your model provider at provider rates. JetBrains AI Free and paid plans use credits.

How much does Junie cost?

Junie is included in JetBrains AI plans: Pro is about $10 per user per month and Ultimate about $30, with Junie's page showing Pro at $8.33 on its billing term. Enterprise is custom.

Which IDEs support Junie?

Junie works in JetBrains IDEs such as IntelliJ IDEA, PyCharm, WebStorm and GoLand, and a catalogue says it also works in Android Studio and previews support in Visual Studio.

Does Junie support local models?

Yes. Junie's page says it supports locally running models via Ollama.

Is Junie autonomous?

We classify it as an agentic tool. Reviews describe planning, multi-file edits and test runs, with developers reviewing results.

How does Junie compare with GitHub Copilot?

Junie is IDE-native for JetBrains and LLM-agnostic, while Copilot works across many IDEs and GitHub. See the GitHub Copilot vs Junie comparison.

What integrations does Junie support?

Documented integrations and ecosystem items include IntelliJ IDEA, PyCharm, WebStorm, GoLand and other JetBrains IDEs, Junie CLI, GitHub Action, ACP, Ollama and BYOK providers, Visual Studio via ACP (preview, per a catalogue). API details: Bring your own key from supported providers.

What are the limitations of Junie?

Credit-based plans can run out with heavy agent use. The CLI is in beta. AI subscription is separate from the IDE licence, per a review.

Which platforms does Junie run on?

Junie is documented as available on: JetBrains IDEs, Terminal (beta CLI), GitHub Actions.

Is Junie an AI agent or an AI assistant?

We classify Junie as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

When was the Junie profile last verified?

4 sources are listed under Sources. Prices and plans can change, so confirm with the vendor.

What are the main alternatives to Junie?

The main alternatives to Junie covered on Stack18 are GitHub Copilot, Cursor, Claude Code and Cline. GitHub Copilot may suit developers and teams standardised on GitHub. Cursor may suit developers who prefer an editor-centred workflow. Claude Code may suit Terminal-first developers. See the Junie alternatives guide for a side-by-side table.
