Quick answer

What is Ona?

Ona, formerly Gitpod, is a platform for background software engineering agents that work in isolated, ephemeral cloud development environments with kernel-level guardrails and audit trails. It can run entirely inside a customer's VPC.

  • Best forRegulated enterprises
  • PricingCore from $20 per month (OCU-metered); Enterprise custom.
  • Main limitationNo free plan since 2026.
  • AlternativesDevin · Tembo · OpenAI Codex · compare all

Reviewed by the Stack18 editorial team · 5 sources

Overview

Ona overview: who it is for and what it does.

Gitpod rebranded to Ona on 2 September 2025, repositioning from cloud development environments to "the platform for background agents": assign a task and agents plan, code, test and open a pull request in a sandboxed environment. Ona Guardrails adds policy enforcement and audit trails, and customers include banks such as BNY.

On 11 June 2026 OpenAI announced it would acquire Ona to give Codex persistent cloud execution. Ona removed its free plan in 2026; Core starts at $20 a month with usage metered in OCUs, and Enterprise is custom.

Main problem it solves

Runs autonomous agents safely in isolated, governed environments that can stay inside the customer's network.

Typical customer segment

Regulated enterprises and engineering teams.

Target users

  • Engineering managers with large backlogs
  • Platform and DevEx teams
  • Teams using Linear, Jira or Slack

Primary use cases

  • Background agents in sandboxes
  • VPC-contained agent work
  • Governed agent access with audit trails
  • Cloud development environments

What makes it distinct

  • Sandboxed environments with kernel-level guardrails.
  • Runs inside your VPC.
  • OpenAI acquisition announced June 2026.

What is Ona used for?

Ona, formerly Gitpod, is a platform for background software engineering agents that work in isolated, ephemeral cloud development environments with kernel-level guardrails and audit trails. It can run entirely inside a customer's VPC.

Is Ona free?

No. The free plan was removed in 2026.

How much does Ona cost?

Core from $20 per month (OCU-metered); Enterprise custom.

Which models does Ona support?

Codex, Claude Code, AWS Bedrock and Google Vertex models.

Is Gitpod now Ona?

Yes. Gitpod rebranded to Ona on 2 September 2025 and refocused on background agents.

Did OpenAI acquire Ona?

OpenAI announced on 11 June 2026 that it would acquire Ona to give Codex persistent cloud execution.

What are the limitations of Ona?

No free plan since 2026. OCU metering requires usage monitoring. OpenAI's announced acquisition may change the roadmap.

Is Ona an AI agent or an AI assistant?
