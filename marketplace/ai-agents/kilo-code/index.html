Quick answer

What is Kilo Code?

Kilo Code is an open-source AI coding agent that runs in VS Code, JetBrains IDEs and the terminal, with cloud agents, a Slack integration and code reviews. It works with 500+ hosted, bring-your-own-key or local models, and its Kilo Gateway charges provider rates without markup.

Overview

Kilo Code overview: who it is for and what it does.

Kilo Code launched in March 2025 in the same lineage as Cline and Roo Code and has grown into a broader platform. Its MIT-licensed VS Code, JetBrains and CLI clients offer Code, Architect, Debug, Ask and Orchestrator modes, and the company adds cloud agents, Slack and code reviews on top.

The extension is free. Model usage goes through your own keys, local models or the Kilo Gateway at provider rates. Optional Kilo Pass subscriptions ($19, $49 and $199 a month) add bonus credits, Teams costs $15 a user, and cloud agents and code review are billed per second of compute.

Main problem it solves

Gives developers a free, open-source agent with any model and transparent pass-through pricing, across IDEs and the terminal.

Typical customer segment

Individual developers through enterprises.

Target users

  • Developers who want an open-source agent with any model
  • Teams that want shared modes and usage analytics
  • JetBrains and VS Code users who also work in the terminal

Primary use cases

  • Multi-mode agent work (Architect, Code, Debug)
  • Orchestrating subtasks across agents
  • Cloud agents and Slack-triggered tasks
  • AI code reviews

What makes it distinct

  • MIT-licensed clients with 500+ models and no token markup.
  • Orchestrator mode for breaking work into subtasks.
  • IDE, CLI, cloud and Slack surfaces in one product.

FAQ

Kilo Code questions and answers

What is Kilo Code used for?

Kilo Code is an open-source AI coding agent that runs in VS Code, JetBrains IDEs and the terminal, with cloud agents, a Slack integration and code reviews. It works with 500+ hosted, bring-your-own-key or local models, and its Kilo Gateway charges provider rates without markup.

Is Kilo Code free?

Yes. The extensions are free and open source; you pay only for model usage or bring your own keys.

How much does Kilo Code cost?

Free and open source; Teams $15 per user; Kilo Pass $19 to $199 per month.

Which models does Kilo Code support?

500+ hosted, BYOK or local models, including Claude, GPT, Gemini and Grok.

What are the limitations of Kilo Code?

Model usage is billed separately unless you bring your own keys. Gateway and Cloud backend are source-available, not MIT. Many modes and options can mean more setup.

Which platforms does Kilo Code run on?

Kilo Code is documented as available on: VS Code, JetBrains IDEs, CLI, Cloud, Slack.

Is Kilo Code an AI agent or an AI assistant?

We classify Kilo Code as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

What are the main alternatives to Kilo Code?

The main alternatives to Kilo Code covered on Stack18 are Cline, Roo Code, Continue and OpenCode. See the Kilo Code alternatives guide for a side-by-side table.
