Quick answer

What is GitHub Copilot?

GitHub Copilot is GitHub's AI coding product. It combines inline code completions, Copilot Chat, agent mode, a cloud agent that works on issues and pull requests, a command-line agent (Copilot CLI) and code review, available in major IDEs and on GitHub.com.

  • Best forDevelopers and teams standardised on GitHub
  • PricingFree plan; Pro $10, Pro+ $39 and Max $100 per month; Business $19 and Enterprise $39 per user per month. Free plan available.
  • Main limitationAgent, chat and CLI usage is metered in AI credits, so heavy use can need a budget for extra usage.
  • AlternativesCursor, Claude Code, OpenAI Codex, Cline · compare all

Overview

GitHub Copilot overview: who it is for and what it does.

GitHub Copilot started as an autocomplete tool and now spans several surfaces. GitHub's documentation lists code suggestions and next edit suggestions in the editor, Copilot Chat, a cloud agent, Copilot CLI, a GitHub Copilot app, code review, Copilot Spaces and Copilot Memory. Supported IDEs named in the billing documentation include VS Code, Visual Studio, JetBrains IDEs, Eclipse, Xcode and SQL Server Management Studio.

Since June 2026, every Copilot plan uses usage-based billing. Each plan includes a monthly allowance of GitHub AI Credits, where one credit equals one US cent. Chat, the CLI, the cloud agent, Spaces and third-party coding agents consume credits; code completions and next edit suggestions are documented as unmetered on paid plans. Individual plans are Free, Pro, Pro+ and Max, and organisations choose Business or Enterprise.

For teams, GitHub documents content exclusion, enterprise policies, agent management, audit logs, an MCP registry and allowlist, budgets and a Copilot SDK. Copilot Business is for organisations on GitHub Free or Team, or enterprises on GitHub Enterprise Cloud; Copilot Enterprise requires GitHub Enterprise Cloud, and Copilot is not available on GitHub Enterprise Server.

Main problem it solves

Helps developers write, review and ship code faster by putting completions, chat, agents and code review inside the IDEs and the GitHub workflow they already use.

Typical customer segment

Individuals through large enterprises, with Free, Pro, Pro+, Max, Business and Enterprise plans.

Target users

  • Individual developers who want AI help inside their existing IDE
  • Engineering teams on GitHub that want agents working on issues and pull requests
  • Enterprises that need policies, budgets, audit logs and central administration

Primary use cases

  • Inline code completion and next edit suggestions
  • Chat and agent mode inside VS Code, Visual Studio and JetBrains IDEs
  • Delegating issues to a cloud agent that works on a branch
  • Terminal workflows with Copilot CLI
  • AI code review on pull requests

What makes it distinct

  • Built into GitHub, so agents, code review and pull requests share one platform.
  • Supports many IDEs, from VS Code and JetBrains to Eclipse and Xcode.
  • Code completions are documented as unmetered on paid plans, with agent and chat usage metered in AI credits.
Key features

GitHub Copilot features explained.

In the editor

Code completions and next edit suggestions
Real-time suggestions in supported IDEs. GitHub documents them as not billed in AI credits on paid plans; Copilot Free is limited to 2,000 completions per month.
Copilot Chat and agent mode
Chat and agentic edits inside the IDE. These consume AI credits according to the model used and the size of the task.
Custom instructions and prompt files
Repository, personal and organisation instructions plus prompt files to shape responses.

Agents

Copilot cloud agent
Works on tasks in a GitHub-hosted environment and can be started from GitHub.com, GitHub Mobile, the IDE, the API, the GitHub CLI, Slack, Teams, Jira, Linear or Azure Boards, according to GitHub's documentation.
Copilot CLI
A terminal agent with documented features such as autonomous task completion, parallel task execution, session limits in AI credits and rollback.
Third-party coding agents
GitHub documents OpenAI Codex and Anthropic Claude as agents that can be used through Copilot; usage is billed in AI credits.

Review and context

Copilot code review
Automated review of pull requests, with documented customisation and enterprise enablement controls.
Spaces, Memory and repository indexing
Ways to give Copilot persistent context about code, documents and preferences.
MCP, skills, hooks and plugins
Extensibility through the Model Context Protocol, agent skills, hooks and plugins.

Administration

Policies, budgets and audit logs
Enterprise policies, budgets for usage-based billing, agent management and audit logging.
Content exclusion
Admins can exclude files and repositories from Copilot.
MCP registry and allowlist
Enterprise controls over which MCP servers can be used.

FAQ

GitHub Copilot questions and answers

What is GitHub Copilot?

GitHub Copilot is GitHub's AI coding assistant. It offers code completions, chat, agent mode, a cloud agent, a command-line agent and code review in supported IDEs and on GitHub.com.

How much does GitHub Copilot cost?

According to GitHub's documentation, Copilot Pro is $10 per month, Pro+ is $39 and Max is $100 for individuals, while Copilot Business is $19 and Enterprise is $39 per user per month. Copilot Free is available at no cost with limits.

Is GitHub Copilot free?

Yes, with limits. Copilot Free includes a limited allowance of AI credits, auto model selection only and 2,000 code completions per month. Verified students have a separate Copilot Student plan.

What are GitHub AI Credits?

AI credits are GitHub's usage unit since June 2026. One credit equals $0.01, and chat, agent and CLI usage draws credits down based on the model and the number of tokens consumed. Code completions and next edit suggestions are not billed in credits on paid plans.

Is GitHub Copilot an autonomous agent?

We classify it as an agentic tool. It offers agent mode, a cloud agent and a CLI that can make multi-step changes, and GitHub documents approval, rollback and credit-limit controls, so developers stay in the review loop.

Which IDEs does GitHub Copilot support?

GitHub's billing documentation names VS Code, Visual Studio, JetBrains IDEs, Eclipse, Xcode and SQL Server Management Studio, plus the Copilot CLI.

How does GitHub Copilot compare with Cursor?

Copilot is a multi-IDE extension and GitHub platform service, while Cursor is an AI-native editor. See the Cursor vs GitHub Copilot comparison for a side-by-side view.

What integrations does GitHub Copilot support?

Documented integrations and ecosystem items include VS Code, Visual Studio, JetBrains, Eclipse, Xcode, GitHub.com, GitHub Mobile and GitHub CLI, Slack, Teams, Jira, Linear and Azure Boards (cloud agent), MCP servers, skills, hooks and plugins, OpenAI Codex and Anthropic Claude as third-party agents. API details: GitHub documents a Copilot SDK and a way to start cloud agent sessions through the API.

What are the limitations of GitHub Copilot?

Agent, chat and CLI usage is metered in AI credits, so heavy use can need a budget for extra usage. Copilot is not available for GitHub Enterprise Server. The flex portion of individual credit allowances is variable and can change.

Which platforms does GitHub Copilot run on?

GitHub Copilot is documented as available on: IDE extensions, Copilot CLI, GitHub Copilot app, GitHub.com and GitHub Mobile.

Is GitHub Copilot an AI agent or an AI assistant?

We classify GitHub Copilot as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

When was the GitHub Copilot profile last verified?

4 sources are listed under Sources. Prices and plans can change, so confirm with the vendor.

What are the main alternatives to GitHub Copilot?

The main alternatives to GitHub Copilot covered on Stack18 are Cursor, Claude Code, OpenAI Codex and Cline. Cursor may suit developers who prefer an editor-centred workflow. Claude Code may suit Terminal-first developers. OpenAI Codex may suit ChatGPT subscribers who write code. See the GitHub Copilot alternatives guide for a side-by-side table.
