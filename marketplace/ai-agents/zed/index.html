Quick answer

What is Zed?

Zed is a high-performance, open-source code editor from Zed Industries, written in Rust, with a native agent panel, Zeta edit predictions and real-time collaboration. It runs on macOS, Linux and Windows and can host external agents through the Agent Client Protocol.

Overview

Zed overview: who it is for and what it does.

Zed is a code editor built in Rust for speed, with multiplayer collaboration and AI features built in. Its agent panel lets developers ask an agent to make changes, while Zeta, Zed's open-weight model, powers edit predictions as they type.

Zed is open about where AI comes from. The free Personal plan allows unlimited use with your own API keys or with external agents such as Claude Agent, Codex and Gemini CLI connected through the Agent Client Protocol (ACP), an open protocol Zed builds with partners including JetBrains.

The paid Pro plan adds Zed-hosted models with a small included token balance and usage billed beyond that at list price plus 10%. A Business plan launched in May 2026 at $30 a seat, adding organisation-wide AI policies, role-based access and spend visibility.

Main problem it solves

Gives developers a fast editor where they can use AI agents and predictions without being locked into one model vendor.

Typical customer segment

Individual developers and teams; Business adds organisation controls, with order forms from 25 seats.

Target users

  • Developers who value editor speed and native collaboration
  • Developers who want to bring their own API keys or external agents
  • Teams that want org-wide AI policies in the editor

Primary use cases

  • Agent-driven edits in the agent panel
  • Edit predictions with the Zeta model
  • Running Claude Code, Codex or Gemini CLI inside the editor via ACP
  • Pair programming with real-time collaboration

What makes it distinct

  • Open-source editor built in Rust for performance.
  • Agent Client Protocol support for external agents, so the editor is not tied to one provider.
  • Low-cost Pro plan at $10 a month after a May 2026 price cut.

FAQ

Zed questions and answers

What is Zed used for?

Zed is used as a fast code editor with a built-in agent, AI edit predictions and the ability to run external agents such as Claude Code or Codex in the editor.

Is Zed free?

Yes. Personal is free forever with 2,000 accepted edit predictions and unlimited use with your own API keys or external agents.

How much does Zed cost?

Free Personal plan; Pro $10 per month; Business $30 per seat per month. Hosted-model usage beyond the included $5 is billed at API list price plus 10%.

Which models does Zed support?

Zed-hosted models including Claude, GPT and Gemini on Pro, the Zeta prediction model, and any provider through your own keys.

Can I use Claude Code inside Zed?

Yes. Zed supports external agents, including Claude Agent and Codex, through the Agent Client Protocol, and the free Personal plan allows unlimited use with external agents.

Is Zed open source?

Yes. Zed is an open-source editor; paid plans add hosted models and team controls.

What are the limitations of Zed?

No SSO, SAML or SCIM was documented in one September 2026 profile. Hosted-model usage beyond the included $5 on Pro is billed at list price plus 10%. The extension ecosystem is smaller than VS Code's.

Which platforms does Zed run on?

Zed is documented as available on: macOS, Linux, Windows.

Is Zed an AI agent or an AI assistant?

We classify Zed as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

What are the main alternatives to Zed?

The main alternatives to Zed covered on Stack18 are Cursor, Windsurf, Trae and GitHub Copilot. See the Zed alternatives guide for a side-by-side table.
