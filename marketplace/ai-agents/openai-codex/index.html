Quick answer

What is OpenAI Codex?

OpenAI Codex is OpenAI's software engineering agent. It runs in a terminal CLI, an IDE extension, a desktop app and a cloud environment, signs in with a ChatGPT account or an API key, and uses OpenAI's models.

  • Best forChatGPT subscribers who write code
  • PricingIncluded with ChatGPT: Go $8, Plus $20, Pro from $100 per month; Business and Enterprise by plan; API key billed per token. Free plan available.
  • Main limitationSupports OpenAI's models rather than several vendors' models.
  • AlternativesClaude Code, GitHub Copilot, Gemini CLI, Cursor · compare all

Overview

OpenAI Codex overview: who it is for and what it does.

OpenAI Codex lets developers delegate coding work to an agent from several places. OpenAI's quickstart describes an IDE extension, a CLI and a cloud agent, and a developer can delegate tasks to the cloud agent from the IDE extension. OpenAI's documentation also covers Codex cloud environments, code review, internet access controls, a TypeScript SDK and a GitHub Action.

There is no separate Codex subscription. OpenAI's pricing page presents Codex as included with ChatGPT plans: Free and Go for light use, Plus at $20 per month, Pro at higher usage tiers, and Business, Enterprise and Edu plans for organisations. Plus lists Codex on the web, in the CLI, in the IDE extension and on iOS, with cloud-based integrations such as code review and Slack. Developers can also use an API key, billed per token at API rates, for the CLI, SDK or IDE extension.

Third-party guides describe the Codex CLI as open source under the Apache-2.0 licence and written in Rust. OpenAI's pricing for Codex has changed during 2026, including a move toward token-based rates, so budgets should be checked against OpenAI's current pricing page.

Main problem it solves

Lets developers hand coding tasks to an OpenAI-powered agent locally or in the cloud, and review the results, without a separate subscription for people who already use ChatGPT.

Typical customer segment

Individuals through enterprises, through ChatGPT Free, Go, Plus, Pro, Business, Enterprise and Edu plans, or an API key.

Target users

  • Developers who already pay for ChatGPT Plus or Pro
  • Teams that want parallel cloud tasks and automated code review
  • Organisations that need ChatGPT Business or Enterprise controls for coding agents

Primary use cases

  • Terminal coding sessions with the Codex CLI
  • Editing in VS Code or JetBrains through the Codex extension
  • Delegating longer tasks to cloud environments
  • Automated code review on GitHub
  • Scripted workflows through the SDK and GitHub Action

What makes it distinct

  • Included with ChatGPT plans, so there is no separate Codex subscription.
  • One agent across CLI, IDE, desktop app, web and iOS.
  • An SDK and GitHub Action for scripted and CI use.

FAQ

OpenAI Codex questions and answers

What is OpenAI Codex?

OpenAI Codex is OpenAI's coding agent. It works in a terminal CLI, an IDE extension, a desktop app and cloud environments, and uses OpenAI's models.

Is OpenAI Codex free?

OpenAI's pricing page lists Codex as included in ChatGPT Free and Go for lighter use, with Plus at $20 per month and higher tiers for heavier use. Free is scoped for exploration, so productive daily use usually needs a paid plan or an API key.

How much does Codex cost?

There is no separate Codex subscription. It is included with ChatGPT plans (Go $8, Plus $20, Pro from $100 per month per OpenAI's pricing and help pages), or billed per token through an API key.

Is the Codex CLI open source?

Third-party guides describe the Codex CLI as open source under the Apache-2.0 licence. Check OpenAI's repository for the current licence.

Is Codex an autonomous agent?

We classify it as an agentic tool. OpenAI documents delegating tasks to a cloud agent, but the sources reviewed here do not describe fully unsupervised operation, and developers review the results.

What is the difference between Codex CLI and Codex cloud?

The CLI and IDE extension run locally in your environment, while Codex cloud runs delegated tasks in OpenAI-hosted environments and enables cloud-based integrations such as code review.

How does OpenAI Codex compare with Claude Code?

Both are terminal-capable agents from model vendors. Codex uses OpenAI models and is bundled with ChatGPT plans, while Claude Code uses Anthropic's Claude models. See the Claude Code vs OpenAI Codex comparison.

What integrations does OpenAI Codex support?

Documented integrations and ecosystem items include GitHub code review, Slack, VS Code and JetBrains IDE extensions, TypeScript SDK and GitHub Action, ChatGPT sign-in or OpenAI API key. API details: Codex can run with an OpenAI API key and has an SDK; API usage is billed at standard API rates.

What are the limitations of OpenAI Codex?

Supports OpenAI's models rather than several vendors' models. API-key use does not include cloud-based features such as GitHub code review and Slack. Pricing and usage measurement changed during 2026, so published guides go stale quickly.

Which platforms does OpenAI Codex run on?

OpenAI Codex is documented as available on: CLI, IDE extension, Desktop app, Web (ChatGPT), iOS.

Is OpenAI Codex an AI agent or an AI assistant?

We classify OpenAI Codex as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

When was the OpenAI Codex profile last verified?

5 sources are listed under Sources. Prices and plans can change, so confirm with the vendor.

What are the main alternatives to OpenAI Codex?

The main alternatives to OpenAI Codex covered on Stack18 are Claude Code, GitHub Copilot, Gemini CLI and Cursor. Claude Code may suit Terminal-first developers. GitHub Copilot may suit developers and teams standardised on GitHub. Gemini CLI may suit developers who want to start free in the terminal. See the OpenAI Codex alternatives guide for a side-by-side table.
