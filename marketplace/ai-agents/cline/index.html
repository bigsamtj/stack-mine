Quick answer

What is Cline?

Cline is an open-source AI coding agent. It runs as an extension in VS Code (with a CLI), can create and edit files, run commands and use tools through MCP, and asks for the developer's approval for actions. It works with the model provider of your choice.

  • Best forDevelopers who prefer open-source tools and their own API keys
  • PricingFree and open source for individuals (pay only for model usage); Enterprise custom. Free plan available.
  • Main limitationModel costs are separate and unpredictable, because heavy agent use can consume many tokens.
  • AlternativesAider, GitHub Copilot, Cursor, Claude Code · compare all

Reviewed by the Stack18 editorial team · 4 sources

Overview

Cline overview: who it is for and what it does.

Cline is an open-source coding agent that lives in the developer's editor. Cline's pricing page says the extension is free for individual developers, with no subscriptions or seat fees for the open-source version, and that users pay only for AI inference on a usage basis. Users can bring their own API keys or use the Cline provider.

Cline lists support for providers such as Anthropic, Google Gemini, OpenAI, OpenRouter, AWS Bedrock, Google Cloud Vertex, Groq, Cerebras, Vercel AI Gateway and DeepSeek, and third-party guides describe local models as another route. Third-party reviews describe a Plan and Act workflow, human approval for each action, checkpoints, MCP support and a CLI.

For organisations, Cline's pricing page describes a custom-priced Enterprise plan for SSO, OIDC, SCIM provisioning, audit logs, VPC deployment, an SLA, OpenTelemetry and dedicated support. Earlier versions of the pricing page described a Teams tier, and one third-party page describes a ClinePass subscription, so plan details have changed and should be confirmed.

Main problem it solves

Gives developers an auditable coding agent in their editor without locking them into one model vendor or an editor subscription.

Typical customer segment

Individual developers (free, open source), with a custom-priced Enterprise plan.

Target users

  • Developers who want to choose and pay model providers directly
  • Teams that want an auditable open-source agent
  • Enterprises that need SSO, SCIM and VPC deployment around a coding agent

Primary use cases

  • Multi-file feature work with approval at each step
  • Running terminal commands and tests from the agent
  • Connecting tools through MCP servers
  • Switching between cloud and local models
  • Team rollout with centralised administration

What makes it distinct

  • Open source and bring-your-own-key, so model choice and model billing stay with the user.
  • Human-in-the-loop approval for actions, per third-party reviews.
  • Supports many model providers, including local models.

FAQ

Cline questions and answers

What is Cline?

Cline is an open-source AI coding agent for VS Code and the terminal. It edits files, runs commands and uses MCP tools, and works with the model provider you choose.

Is Cline free?

Yes for individual developers. Cline's pricing page says the open-source extension is free, with no subscription or seat fee, and you pay only for AI inference.

How much does Cline cost?

The software is free. Your cost is model usage, billed by your provider or through Cline credits. Enterprise is custom-priced, and one third-party page lists a $9.99 per month ClinePass.

Which models does Cline support?

Cline lists Anthropic, Gemini, OpenAI, OpenRouter, AWS Bedrock, Google Cloud Vertex, Groq, Cerebras, Vercel AI Gateway, DeepSeek and others. Third-party guides also describe local models.

Is Cline autonomous?

We classify Cline as an agentic tool. It can plan and carry out multi-step tasks, but third-party reviews describe approval for each action.

What was Cline called before?

Third-party sources say Cline was originally launched as Claude Dev.

How does Cline compare with Aider?

Cline works inside VS Code with approval-based actions, while Aider is a terminal tool built around Git commits. See the Cline vs Aider comparison.

What integrations does Cline support?

Documented integrations and ecosystem items include VS Code, Cline CLI, MCP servers, Anthropic, OpenAI and Google models, AWS Bedrock and Google Cloud Vertex, OpenRouter and local models. API details: Bring your own API key from supported providers, or use the Cline provider.

What are the limitations of Cline?

Model costs are separate and unpredictable, because heavy agent use can consume many tokens. Setup needs an API key or credits before use, which adds friction compared with a bundled subscription. Plan names and prices have changed across versions of the pricing page.

Which platforms does Cline run on?

Cline is documented as available on: VS Code extension, CLI.

Is Cline an AI agent or an AI assistant?

We classify Cline as: Agentic tool. A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes. The classification is based on vendor documentation and is not an endorsement.

When was the Cline profile last verified?

4 sources are listed under Sources. Prices and plans can change, so confirm with the vendor.

What are the main alternatives to Cline?

The main alternatives to Cline covered on Stack18 are Aider, GitHub Copilot, Cursor and Claude Code. Aider may suit developers who live in the terminal and use git heavily. GitHub Copilot may suit developers and teams standardised on GitHub. Cursor may suit developers who prefer an editor-centred workflow. See the Cline alternatives guide for a side-by-side table.
