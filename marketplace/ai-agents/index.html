    How we classify AI products
    • Autonomous agent Completes multi-step tasks with tools and limited supervision, as documented by the vendor.
    • Agentic tool A human-directed tool that can plan, edit and run actions, with the user reviewing or approving changes.
    • AI assistant Answers questions and suggests content or code; the user performs the actions.
    • Software with AI features Conventional software that includes AI features rather than being built around an agent.
