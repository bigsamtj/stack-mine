    What is AI Coding Agents?

    An AI coding agent is software that uses large language models together with tools, such as file editing and shell commands, to carry out programming tasks. Most current products are human-directed: the developer reviews or approves changes, which is why we describe them as agentic tools rather than fully autonomous agents.

    Also called Coding Agents, AI Development Agents, AI Programming Assistants

    Reviewed by the Stack18 editorial team

    Key takeaways

    • 72 profiles in this category, listed alphabetically and not ranked.
    • 55 of 72 offer a free plan or program.
    • $19–$40 reported entry price per user per month. Confirm current pricing with each vendor.
    • Check first: Interface and workflow fit, Model choice, Permissions and human oversight.
    • Sourcing: 18 vendor-sourced and 4 independent-source profiles, each with dated links.

    AI coding agents go beyond autocomplete. Given a task, they can read a repository, plan changes across several files, run commands such as tests, and propose or apply edits for a developer to review.

    Products in this category differ in where they run (a purpose-built editor, a terminal, an IDE extension or a cloud environment), which models they use, how much they act without asking, and how usage is billed. Those differences matter more than headline capability claims.

    We classify each listing as an agentic tool, an assistant or an autonomous agent only where vendor documentation supports it, and we label anything not documented as unknown.

    How to choose AI Coding Agents: a step-by-step approach.

    3. 3

    Common mistakes

    Common mistakes when choosing AI Coding Agents.

    Judging on demos

    Demos use clean projects. Evaluate on your own codebase, conventions and test suite.

    Ignoring review effort

    Faster code generation is not a gain if reviewing and fixing the output takes longer than writing it.

    Skipping the data policy

    Check how your code and prompts are handled before connecting a private repository.

    Leaving permissions wide open

    Decide in advance which commands and files an agent may touch without approval.

    Assuming one tool fits every workflow

    Editor-centred and terminal-first tools suit different habits, and teams often need to test both.

    Glossary

    AI Coding Agents key terms explained.

    Agentic coding
    Using an AI system that plans and carries out multi-step programming tasks with tools, rather than only suggesting code.
    Context window
    The amount of text a model can consider at once. Large repositories usually exceed it, so tools must select what to include.
    MCP (Model Context Protocol)
    An open protocol for connecting AI tools to external data sources and tools.
    Subagent
    A helper agent with its own context and tools that handles a sub-task and reports back to the main session.
    Sandboxing
    Restricting what an agent's commands can access on a machine so mistakes or unwanted actions have limited impact.
    Human-in-the-loop
    A workflow in which a person reviews or approves the agent's actions before they take effect.

    AI Coding Agents questions and answers

    Which AI coding agents are free?

    55 of the 72 AI coding agents profiles here document a free tier or free open-source use (model usage may still be billed): Aider, Amazon Q Developer, Amp, Anything, Base44, Bolt.new, Builder.io Fusion, Cline and 47 more. Free plans and tiers usually cap users, records or usage, so check each profile for limits. The list is alphabetical, not a ranking.

    Which AI coding agents run in the terminal?

    38 profiles document a terminal or CLI interface: Aider, Amp, Augment Code, Bito, Blackbox AI, Claude Code, Cline, Codebuff and 30 more.

    Which AI coding agents work inside VS Code or JetBrains?

    35 profiles document an IDE extension or AI code editor: Amazon Q Developer, Amp, Augment Code, Bito, Blackbox AI, Claude Code, Cline, CodeRabbit and 27 more. Check which IDEs each one supports on its profile.

    Which AI coding agents run in the browser or the cloud?

    41 profiles document a web or cloud interface: Anything, Base44, Bito, Blackbox AI, Bolt.new, Builder.io Fusion, Claude Code, Codegen and 33 more.

    Which AI coding agents let you choose the model?

    43 profiles support models from more than one vendor: Aider, Amp, Augment Code, Bito, Blackbox AI, Cline, Codebuff, Codegen and 35 more. Some bundle model usage in a subscription; others bill it through your own API keys.

    Where can I find alternatives to a specific AI coding tool?

    Every product in this category has its own alternatives guide, for example Claude Code alternatives, Cursor alternatives and GitHub Copilot alternatives. Each guide compares the main competitors on pricing, free plan, features and fit.

    Is an AI coding agent the same as an AI code assistant?

    Not exactly. An assistant mainly suggests code or answers questions. An agent can also take actions, such as editing several files or running commands, usually under user approval. Products often combine both modes.

    Are AI coding agents fully autonomous?

    The tools listed here are directed by a developer who reviews or approves changes. We only describe a product as autonomous when its vendor documentation says so.

    How should I test an agent on a large codebase?

    Run the same real task, such as a cross-module refactor with tests, in each candidate on a branch of your own repository, and compare correctness, review effort, cost and how well the tool handles project context.

    What should security teams check first?

    Start with the vendor's data-retention and training policy, which commands and files the tool can access, whether permissions can be enforced centrally, and the availability of SSO and audit controls.

    Which AI coding agents are listed here?

    The directory currently profiles 72 agents, including Claude Code, Cursor, GitHub Copilot, OpenAI Codex, Windsurf, Zed, Devin, Cline, Kilo Code, CodeRabbit, Greptile, Lovable, v0, Base44 and Tabnine. It covers editors, IDE extensions, terminal agents, background agents, AI code reviewers and AI app builders.

    Which AI coding agents are free or open source?

    Cline, Aider, Gemini CLI, OpenHands, Roo Code, goose and OpenCode are open source, and Warp's client is reported to be open source too. Cursor, GitHub Copilot, Devin, Replit Agent, Kiro, Lovable, Jules, Amp, Bolt.new and Junie have free plans or free routes with limits. Model usage is often billed separately, so use the filters on this page and check each profile.

    What is the difference between a coding agent in the terminal, an editor and the cloud?

    Terminal agents such as Claude Code, Aider and Gemini CLI work in your shell, editor agents such as Cursor and Kiro sit inside a purpose-built IDE, and cloud agents such as Devin, the GitHub Copilot cloud agent and Codex cloud run tasks in hosted environments. Many products offer more than one.
