Cloud, Infrastructure & Security

The infrastructure modern software runs on and how it is protected: cloud, containers, Kubernetes, IaC, cybersecurity and encryption.

Cloud ComputingCloud-Native ArchitectureContainerizationCybersecurityData EncryptionInfrastructure as CodeKubernetesServerless Computing

Cloud Computing

Cloud computing is the delivery of computing resources, such as servers, storage, databases, networking and software, over the internet on demand, typically paid for by usage. Instead of buying and running physical hardware, organisations rent capacity from providers such as Amazon Web Services, Microsoft Azure or Google Cloud and scale it up or down as needed.

Cloud-Native Architecture

Cloud-native architecture is an approach to designing and running applications that takes full advantage of cloud computing. Cloud-native systems are typically built from loosely coupled services, packaged in containers or run as serverless functions, use managed cloud services, scale automatically and are deployed and managed through automation.

Read the full definition →4 FAQs · 3 min read

Containerization

Containerization is a way of packaging an application together with its code, runtime, libraries and settings into a lightweight, standardised unit called a container. Containers run consistently on any system that supports them, isolated from each other while sharing the host machine's operating system kernel, which makes them faster and lighter than virtual machines.

Read the full definition →4 FAQs · 3 min read

Cybersecurity

Cybersecurity is the practice of protecting computer systems, networks, applications and data from attacks, unauthorised access, damage and disruption. It combines technology, processes and people: access controls, encryption, secure software development, monitoring, incident response and staff awareness, all aimed at keeping information confidential, accurate and available.

Read the full definition →4 FAQs · 3 min read

Data Encryption

Data encryption is the process of converting readable information into an unreadable form, called ciphertext, using a mathematical algorithm and a key. Only someone with the correct key can decrypt it back into readable form. Encryption protects data stored on devices and servers (at rest) and data moving across networks (in transit) from being read if it is stolen or intercepted.

Read the full definition →4 FAQs · 3 min read

Infrastructure as Code (IaC)

Infrastructure as code (IaC) is the practice of defining and managing computing infrastructure, such as servers, networks, databases and permissions, through machine-readable configuration files rather than manual setup. The files are version-controlled like application code, so environments can be created, changed and recreated consistently and automatically.

Read the full definition →4 FAQs · 3 min read

Kubernetes

Kubernetes (often written K8s) is an open-source platform that automates the deployment, scaling and management of containerised applications across a cluster of machines. You describe the desired state, such as how many copies of a service should run, and Kubernetes continuously works to keep the system in that state, restarting failed containers and distributing traffic.

Read the full definition →4 FAQs · 2 min read

Serverless Computing

Serverless computing is a cloud model in which developers run code, or use services such as databases and queues, without provisioning or managing servers. The cloud provider automatically allocates capacity when the code is triggered, scales it with demand and charges only for the actual execution time and resources used.
